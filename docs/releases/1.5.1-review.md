# Review Snurpo 1.5.1

This proposal carries the original changes from #47 in their existing commits,
plus the version, release notes and website source for a patch release.

- Wait for the full captured exchange before enabling cURL or replay. Keep
  request actions disabled after a failed read and offer a retry.
- Apply search and traffic status across the full selected session before cursor
  pagination. Existing archive and MCP callers retain their current interfaces.
- Document the correct cURL executable for Windows PowerShell 5.1.
- Keep the full npm audit in CI and release builds. Confirm withdrawal of the
  single picomatch advisory through GitHub before accepting its known dev-only
  dependency chain. The published CVE and scope are recorded in
  `docs/DEPENDENCIES.md`.

Review the delayed/failed detail read and old-error regressions, and check that
the npm and Rust lock changes only update Snurpo's own version. Required checks
on macOS, Windows and Linux must pass for this exact branch commit. After
maintainer approval, merge, tag the reviewed version and verify the draft
packages before publishing.
