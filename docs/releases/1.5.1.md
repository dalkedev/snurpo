# Snurpo 1.5.1

- **Copy as cURL** and **Compose replay** wait for the full captured request.
  If the archive read fails, the inspector offers a retry.
- **Errors**, other traffic filters and search now apply to the entire selected
  session. **Load more requests** continues through older matches, including
  those beyond the previous 1,000-row limit.
- The first-capture guide shows which cURL executable to use in Windows
  PowerShell 5.1.

Saved sessions, certificate trust and MCP configuration stay compatible. The
separate HAR comparison CLI remains at 0.1.0.
